# 🚌 School Transport Management System — Frontend

A modern React dashboard for managing school transport operations. Built with Vite, Tailwind CSS, and Axios.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Routing:** React Router v6
- **Charts:** Recharts
- **PDF/CSV Export:** jsPDF, Papa Parse

---

## ✅ Features

1. **Admin Dashboard** — overview of trips, drivers, students, payments
2. **Analytics Page** — charts for trip trends, attendance, revenue
3. **Schools Management** — add and view multiple schools
4. **Driver Management** — CRUD for drivers and performance tracking
5. **Student Management** — enroll students, assign vehicles
6. **Trip Management** — schedule, start, and complete trips
7. **Live Tracking** — real-time GPS location per trip
8. **Payments** — record and track school transport fees
9. **Attendance** — mark and view student attendance per trip
10. **Reports** — export PDF and CSV reports
11. **Driver Dashboard** — personal trip view + SOS emergency button
12. **Parent Dashboard** — view child's trips, payments, notifications
13. **Role-Based Login** — Admin, Driver, and Parent dashboards

---

## 🚀 Running the Frontend

```bash
cd transport-frontend
npm install
npm run dev
```

Frontend runs on: `http://localhost:5174`
